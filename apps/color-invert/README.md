# Color Invert

Toggles display color inversion on the Titan 2 Elite, via Shizuku. Same
silent pattern as Tablet Mode: launch, flip
`accessibility_display_inversion_enabled`, verify it stuck, exit.

**Untested on-phone as of first publish.** If it silently does nothing on
your ROM, Unihertz may use a different inversion key — please open an
issue with your ROM/firmware version.

Deliberately does **not** use the quick-settings "inversion" tile: on this
ROM, clicking quick-settings tiles crashed SystemUI for the Scroll
Assistant tile, and the tile route is not trusted here.

Requires Shizuku running, with Invert granted in the Shizuku app.
